# Deployment Options

Deployment options control how JellyCloud integrates with your Kubernetes cluster and how workload scheduling decisions are made.

- [Cluster Deployment](./cluster-deployment) — Configure how the JellyCloud Operator is installed and what RBAC scope it is granted. Choose between full cluster visibility or namespace-scoped access for security-sensitive environments.
- [Policies](../policies/index) — Fine-tune workload placement and scheduling behavior using labels on your workload manifests.
