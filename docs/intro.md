# Welcome to JellyCloud

JellyCloud is a SaaS platform that helps DevOps and platform teams deploy, scale, and operate cloud infrastructure — including AI workloads — without the complexity.

## What is JellyCloud?

JellyCloud abstracts away the heavy lifting of cloud operations. Whether you're running containerized microservices, managing GPU-backed AI inference, or orchestrating multi-region deployments, JellyCloud gives your team a unified control plane.

## Key capabilities

| Capability | Description |
|---|---|
| **Multi-cloud orchestration** | Deploy and manage workloads across AWS, GCP, Azure, and bare metal |
| **AI serving** | First-class support for LLM and ML model inference at scale |
| **GitOps-native** | Declarative configuration synced from your Git repositories |
| **Observability** | Built-in metrics, logs, and traces for every workload |
| **Secrets management** | Encrypted secret injection with zero-trust access policies |
