# Lambda Labs

## Connect your account {#credentials}

Connect your Lambda Labs account to JellyCloud using an API key.

### 1. Generate an API key

1. Log in to the [Lambda Cloud dashboard](https://cloud.lambdalabs.com/).
2. Click your profile icon and go to **API Keys**.
3. Click **Generate API Key**, give it a name, and copy the key. It is only shown once.

### 2. Add to JellyCloud

In the Console, navigate to the **Providers** page, select **Lambda Labs**, and click **Apply**. Paste your API key and click **Continue**. JellyCloud will validate the credentials before storing them in a secured secret manager.
