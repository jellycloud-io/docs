# Contact Support

## Self-service resources

Before reaching out, check:

- [FAQ](./faq) — common questions answered
- [Troubleshooting guide](./troubleshooting) — step-by-step diagnostics
- [Status page](https://status.jellycloud.io) — live platform status and incident history

## Get in touch

| Channel | Best for | Response time |
|---|---|---|
| [support@jellycloud.io](mailto:support@jellycloud.io) | General questions, billing | 1 business day |
| [Dashboard chat](https://app.jellycloud.io) | Quick questions while logged in | A few hours |
| [GitHub Issues](https://github.com/jellycloud/agent/issues) | Agent bugs and feature requests | Best effort |

## Enterprise support

Enterprise customers have access to a dedicated Slack channel and a named customer success engineer. Contact [sales@jellycloud.io](mailto:sales@jellycloud.io) to learn more.

## Provide feedback on the docs

Found an error or missing information in these docs? Use the **Edit this page** link at the bottom of any doc page to open a GitHub pull request.
