# Configuration

The [Quick Start](/quick-start) gets JellyCloud running with the default setup. These pages cover everything you can configure beyond it.

- **[Cluster Setup](/configuration/cluster-setup):** how the JellyCloud Operator is installed, namespace-scoped access, cluster-wide defaults (`ClusterConfig`), private registries, and managed Kubernetes services.
- **[Nodes and Node Pools](/configuration/nodes-and-node-pools):** startup scripts and provider overrides for self-hosted nodes, and all Node Pool settings.
- **[Volumes](/configuration/volumes):** shared storage placement, static PVCs, shared file systems, storage on self-hosted nodes, and volume lifecycle.
- **[Workload Policies](/configuration/workload-policies):** control where workloads run with `WorkloadConfig` resources, and the supported labels and annotations.
